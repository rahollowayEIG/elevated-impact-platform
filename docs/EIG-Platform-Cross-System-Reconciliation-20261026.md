## 4. Reconcile, don't rebuild: implementation sequence

1. **Freeze the inventory:** Identify exact authoritative Live, Sandbox, Build Lab and Golf app deployments by project, git branch/commit, URL, backend ID and distinctive UX. Flag anything unverified. No deletion until owner acceptance and rollback.
2. **Inspect current persistent sources:** Inventory current Supabase `platform_google_drive_folders` + event folder/Sheet IDs and verify mapped Google parentage. Read the existing Project Architect, Functionality Map, audit baselines and GitHub Actions for reusable detectors; identify missing registry schema only after checking schemas and migrations.
3. **Complete *one* internal Platform Registry (not the Product/Gift Registry):** Supabase should hold immutable application IDs, environment records, scoped resources, version/approval status, last successful evidence stamp and canonical Google Drive file/folder IDs. Reuse `platform_google_drive_folders` for actual Google Drive resources, not as a substitute for app/version records.
4. **Chat decision capture with provenance:** Recover prior conversations by dates/keywords; mark owner-confirmed decision vs assistant proposal; link it to a stable requirement ID, app/version, and superseded decision when applicable. An automation **cannot assume it has unrestricted access to all ChatGPT chat histories**; capture explicitly accepted decisions through a user-authorized workflow or reviewed import, then let scanners use the stored decision ledger.
5. **Read-only session preflight:** For an approved app scope, compare registry against current GitHub code and PRs, Vercel production alias/immutable SHA, selected Supabase schema/function version and existing Drive folder IDs. Refuse mismatched links. Present 'known, missing, conflicting, next action' before coding.
6. **Approved completion handoff:** After owner-reviewed tests and release, record the change/PR/deployment/test and exact continuation step to the same registry. Publish an operational read-only view/snapshot into the **existing** EIG Google Workspace hierarchy using the recorded folder IDs, with idempotent upsert and audit. Avoid a second manual master spreadsheet.
7. **Safe retirement:** Verify old URLs, event email links, QR codes, installed desktop shortcuts and recovery dependencies; then mark superseded interfaces, remove stale navigation, and retire unused branches/aliases only with approval. No mass deletes, account changes or real-customer side effects.
